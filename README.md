# FPV Kamikaze Drone — Shield (фикс вылета браузера серверов)

**Временное решение, пока разработчик (HFM Games) не починит игру.**

## В чём проблема

При открытии вкладки **«ВЫДЕЛЕННЫЕ СЕРВЕРЫ»** игра мгновенно вылетает с `Fatal error!`.
Причина — чужие **фейковые сессии `b0nehack.cc`** (реклама чита) с «битым» адресом
`127.0.0.1`, которые спамят в общий список. Клиент (плагин EOS Integration Kit) при
разборе такой записи падает. Это баг игры, срабатывает **у всех**.

## Что делает «щит»

Пока ты играешь, он на лету **убирает фейковые сессии/лобби из списка** до того, как игра
начнёт их показывать. Итог: **«Выделенные серверы» открываются без вылета**, а список чистый.

- Файлы игры **НЕ изменяются**.
- У игры **нет анти-чита** (ни EasyAntiCheat, ни BattlEye) — **бан не грозит**.
- Весь код открыт, можешь посмотреть: [`eos_shield.js`](eos_shield.js).

## Как поставить (самый простой способ)

1. Открой вкладку **Releases** этого репозитория и скачай **`fpvkd_shield.exe`**.
2. **Запусти игру** FPV Kamikaze Drone, дойди до главного меню.
3. **Запусти `fpvkd_shield.exe`** (двойной клик). Откроется чёрное окно — не закрывай его.
   Когда увидишь строку **«ЩИТ АКТИВЕН»** — всё готово.
4. Играй. Открывай «Выделенные серверы» как обычно — вылета больше не будет.

> ⚠️ **Антивирус / SmartScreen могут ругнуться.** Это **ложная тревога**: программа
> маленькая, без подписи, и «встраивается» в игру — для антивирусов это выглядит
> подозрительно, хотя ничего вредного она не делает (код открыт, смотри выше).
> Если выскочит синее окно Windows: **«Подробнее» → «Выполнить в любом случае»**.
> Не доверяешь .exe — запусти из исходника (ниже).

## Запуск из исходника (для продвинутых)

```
pip install frida
```
Запусти игру, затем:
```
python shield_runner.py
```
(или двойной клик по `start_shield.bat`). Файл `eos_shield.js` должен лежать рядом.

## Собрать .exe самому

```
pip install pyinstaller frida
python build_exe.py
```
Готовый файл появится в `dist/fpvkd_shield.exe`.

## Важно

- Это **обход на твоём ПК**, а не настоящее исправление. Нормально починить игру и
  забанить спамеров может только разработчик.
- Если спамеры сменят схему — фильтр, возможно, придётся обновить.
- Проект не связан с HFM Games и Epic Games. Используешь на свой страх и риск.
